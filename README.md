# Skills

A collection of specialized skill modules and tools.

## Contents

- **rowing-coach** - Rowing coaching and training tools. Parses FIT files from rowing sessions (Concept2, Garmin, SpeedCoach) and generates detailed training reports with pacing charts, coach reviews, and social media images.
- **nk-logbook-downloader** - Downloads workout FIT files from the NK Sports logbook (logbook.nksports.com) via internal API. Automatically invokes the rowing-coach skill on new downloads.

## Getting Started

Each subdirectory contains its own specialized functionality. Navigate to individual skill directories for more specific documentation.
